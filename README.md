# MHR-Inven-Monster-Extension

몬스터헌터 라이즈: 선브레이크(MHR:SB) 인벤 몬스터 정보 페이지 기능을 확장하는 **Chrome Extension (Manifest V3)**.

몬헌 인벤 몬스터 페이지를 보며 괴이 탐구 퀘스트 및 무기/속성 세팅을 할 때 필요한 핵심 정보를 인벤 웹페이지에 직접 주입하여 직관적으로 확인하고 빠르게 검색할 수 있도록 지원합니다.

---

## 🌟 주요 기능

### 1. 인벤 몬스터 검색 페이지 바로가기
- 툴바의 확장 프로그램 아이콘 클릭 시 [인벤 몬스터 정보 페이지](https://mhf.inven.co.kr/dataninfo/mhr/monster/)로 즉시 이동

### 2. 강력한 커스텀 검색 및 괴이탐구 필터
1. **고급 이름 검색 문법 (Query Modifiers)**
   * **다중 검색 (`/`)**: `가란/디아` ➔ `가란고르무`, `디아블로스` (OR 검색)
   * **일반종만 검색 (`!`)**: `레이아!` ➔ 주인, 아종, 희소종 제외하고 일반 `리오레이아`만 검색
   * **희소종/아종만 검색 (`@`)**: `레이아@` ➔ `리오레이아 희소종` 등만 검색
   * **주인 몬스터만 검색 (`#`)**: `레이아#` ➔ `주인 리오레이아`만 검색
   * **복합 조합 검색**: `야츠!/벨리/레이아@` ➔ 각 조건이 결합된 다중 필터링
   * **입력창 가이드 제공**: 이름 검색창 하단에 문법 안내 팁(`💡`) 및 플레이스홀더 제공
2. **괴이 탐구(Anomaly) 매트릭스 퀵 필터**
   * 상단에 **EX1 ~ EX9** 레벨 구간 및 괴이 소재별 인터랙티브 매트릭스 테이블 제공
   * 레벨 또는 소재 클릭 시 해당 몬스터만 즉시 필터링 (토글 해제 지원)
   * **실시간 상태 바**: 현재 선택된 필터 태그, 검색 결과 카운트(`결과: N마리`), **원클릭 전체 초기화 (`↺ 전체 초기화`)** 버튼 지원

### 3. 직관적인 몬스터 공략 정보 시각화
1. **사진 좌상단 `Ex N` 플로팅 뱃지**: 
   * 몬스터 썸네일 좌상단에 등급별 전용 컬러(Ex 1~4: 핑크, Ex 5~6: 블루, Ex 7~8: 인디고, Ex 9: 바이올렛) 플로팅 뱃지 부착
2. **단계별 괴이 소재 화살표 흐름 (Stepped Flow)**:
   * 몬스터 이름 하단에 퀘스트 난이도별 파밍 진화 단계(`소재1 ➔ 소재2 ➔ 소재3`)를 중앙 정렬로 단정하게 렌더링
   * 회색 줄무늬 행에서도 뚜렷하게 식별 가능한 고대비 화살표(`➔`) 적용
3. **인게임 핵심 공략 팁 뱃지**:
   * 특수 기믹이나 약점 팁(예: `💡 풍압 ➔ 독 유효`)을 단정한 앰버/골드 뱃지로 표시
4. **'유효속성' 컬럼 속통/약특 정보 일원화 & 수직 일렬 정렬**:
   * 인벤 기본 `유효속성` 열 내 각 속성 라인 우측 끝에 속통룡주/약특 이모지를 수직 일렬(`Flex Space-between`)로 직접 병합
   * `🌠` : 속통룡주 추천 (속성 육질 25 이상)
   * `⭐` : 약점특효-속성 추천 (속성 육질 20 이상)
   * `⚠️` : 속성 비추천
5. **'특효' 컬럼 슬림화 (물리 백룡 장식품 1~2칸)**:
   * 해당 몬스터에 실제로 유효한 물리 특효주만 1~2줄로 컴팩트하게 표시
   * `공`: 파공룡주 (비행 몬스터 대미지 증가)
   * `룡`: 파룡룡주 (조룡/비룡/수룡/해룡/어룡/아룡종 대미지 증가)
   * `류`: 파류룡주 (수서계 몬스터 대미지 증가)
   * `수`: 파수룡주 (아수종 몬스터 대미지 증가)
6. **테이블 상단 범례 가이드 바**: 몬스터 테이블 직전에 속통 및 물리 특효주 설명 바 제공

## 🚀 설치 및 사용 방법

1. 리포지토리의 소스코드를 다운로드하거나 `git clone` 합니다.
2. 크롬 브라우저에서 확장 프로그램 관리 페이지(`chrome://extensions/`)로 이동합니다.
3. 우측 상단의 **[개발자 모드]**를 활성화(ON)합니다.
4. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭하고 프로젝트 폴더를 선택합니다.
5. [인벤 몬스터 정보 페이지](https://mhf.inven.co.kr/dataninfo/mhr/monster/)에 접속하여 확장된 기능을 확인합니다.
